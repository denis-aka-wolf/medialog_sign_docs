# Глоссарий

| Термин | Определение |
|---|---|
| CAdES | Формат электронной подписи для CMS/CAdES |
| CAdES-BES | Базовый профиль CAdES |
| CAdESCOM | COM API для работы с CAdES |
| CSP | Crypto Service Provider, криптопровайдер |
| Detached signature | Отсоединённая подпись, данные хранятся отдельно |
| Attached signature | Присоединённая подпись, данные включены в контейнер |
| Thumbprint | Отпечаток сертификата |
| Bridge | Локальный процесс-посредник между Flutter и CAdESCOM |
| MSIGN | SQL Server schema проекта |
| НетрИка | Внешняя система, с которой проект предусматривает интеграцию |
