## Входные материалы

1. `medialog_sign_cryptopro_module.zip`: исходный Dart-клиент, C# Bridge, README и инструкции сборки.
2. Перечень таблиц схемы MSIGN: 11 имён таблиц.
3. Информация о сервере: SQL Server 2012, версия 11.0.2100.60 x64.
4. Материалы проектных обсуждений по Flutter, структуре БД и сборке.

## Что не было включено

- Бинарные SDK CryptoPro и дистрибутивы CSP.
- Закрытые ключи, сертификаты и производственные настройки.
- Производственные данные БД.
- Архивы исходного кода, не относящиеся к Medialog Sign.
- Декомпилированные исходники стороннего приложения, не относящиеся к этому проекту.
