# План тестирования

## Уровни

1. Unit-тесты Dart-моделей, сериализации и обработки ошибок.
2. Контрактные тесты JSON протокола Bridge.
3. Интеграционные тесты CAdESCOM на Windows x64.
4. Интеграционные тесты MSIGN API и SQL Server.
5. Сквозные сценарии с внешней системой НетрИка.

## CryptoPro Bridge: минимальный чек-лист

- [ ] `status`: COM-компоненты зарегистрированы.
- [ ] `list-certificates`: доступны ожидаемые сертификаты текущего Windows-профиля.
- [ ] Сертификат с закрытым ключом доступен для подписания.
- [ ] Сертификат без закрытого ключа не может быть использован для подписания.
- [ ] Создать отсоединённую подпись тестового файла.
- [ ] Проверить отсоединённую подпись на исходном файле.
- [ ] Изменить байт исходного файла и убедиться в неуспешной проверке.
- [ ] Создать и проверить присоединённую подпись.
- [ ] Проверить отмену PIN-диалога.
- [ ] Проверить заблокированный/недоступный носитель.
- [ ] Проверить истёкший сертификат.
- [ ] Проверить кириллицу в путях.
- [ ] Проверить большой файл.
- [ ] Проверить запуск в RDP и нескольких Windows-профилях.
- [ ] Подтвердить формат подписи у принимающей системы.

## Интеграция с БД

- [ ] Проверить миграции на отдельной тестовой БД SQL Server 2012.
- [ ] Проверить FK и уникальность бизнес-идентификаторов.
- [ ] Проверить повторную отправку одной операции (идемпотентность).
- [ ] Проверить конкурентное подписание документа.
- [ ] Проверить транзакционность регистрации подписи и операции.
- [ ] Проверить аудит успешных и неуспешных операций.
- [ ] Проверить политику хранения файлов и метаданных.

## Безопасность

- [ ] PIN, пароли и секреты не попадают в stdout/stderr и журналы.
- [ ] Закрытый ключ не экспортируется и не передаётся приложению.
- [ ] Проверка подписи отделена от проверки доверия к сертификату.
- [ ] Настроены ACL каталогов с документами и временными файлами.
- [ ] Удаляются временные файлы согласно утверждённой политике.
- [ ] Тесты выполняются на синтетических документах, не на реальных персональных данных.

## Критерий готовности

Релиз нельзя считать готовым к промышленному применению до успешного прохождения интеграционных тестов на целевой Windows-конфигурации и подтверждения совместимости формата подписи с внешней принимающей системой.
