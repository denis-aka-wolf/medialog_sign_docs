# Известные проблемы и диагностика

## Flutter: Expected to find project root

**Симптом:** `flutter pub get` или запуск сообщает `Expected to find project root in current working directory`.

**Причина:** команда выполняется не из корня Flutter-проекта, где расположен `pubspec.yaml`.

**Проверка:**

```powershell
Get-ChildItem pubspec.yaml
Get-Location
```

Перейдите в правильный каталог и повторите `flutter pub get`.

## Bridge не найден

Код: `BRIDGE_NOT_FOUND`.

Проверьте путь, переданный в `CryptoProBridgeClient(executablePath: ...)`, наличие EXE и права запуска.

## Не удалось запустить Bridge

Код: `BRIDGE_START_FAILED`.

Проверьте архитектуру x64, зависимости .NET Framework 4.8, права доступа и системные журналы Windows.

## Некорректный JSON-ответ

Код: `INVALID_BRIDGE_RESPONSE`.

stdout должен содержать только JSON-конверт. Диагностические сообщения C# следует писать в stderr, не смешивая их с протоколом.

## Таймаут

Код: `OPERATION_TIMEOUT`.

Клиент по умолчанию ожидает до 90 секунд. Проверить доступность токена/контейнера, диалог PIN, зависание COM и размер файла. Не увеличивать таймаут как единственную меру исправления.

## COM-компоненты недоступны

Проверить установку и регистрацию x64 CAdESCOM, соответствие разрядности процесса и доступность CryptoPro CSP.

## Проблемы сертификата

Проверить Windows-профиль процесса, наличие сертификата в `CurrentUser\\My`, срок действия и наличие закрытого ключа. Список сертификатов другого пользователя или LocalMachine может не отображаться.

## Статус

Перечень отражает ошибки, предусмотренные исходным Dart-клиентом, и типовые проверки по документации модуля. Не все причины проверялись на реальном Windows-хосте.
