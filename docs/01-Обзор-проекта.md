# Medialog Sign CryptoPro

## Назначение

Medialog Sign CryptoPro предназначен для организации операций электронной подписи документов в контуре Медиалог. В проекте рассматривается клиентское приложение Flutter Desktop, интеграция с КриптоПро CSP/CAdESCOM, серверная часть MSIGN и обмен заданиями с НетрИкой.

> [!warning] Граница подтверждённости
> Наличие таблиц и интеграционного модуля подтверждено предоставленными материалами. Полный сквозной процесс от документа Медиалог до НетрИки и обратно пока не подтверждён интеграционными испытаниями.

## Цели системы

- Получение и учёт документов, подлежащих подписанию.
- Выбор сертификата пользователя.
- Создание электронной подписи с использованием закрытого ключа в доступном криптопровайдеру хранилище.
- Проверка подписи.
- Хранение метаданных документов, сертификатов, подписей и операций.
- Аудит значимых действий.
- Интеграция с внешними системами через отдельные адаптеры.

## Основные технологические области

| Область | Технология / компонент | Состояние |
|---|---|---|
| Desktop UI | Flutter | Прототип/разработка |
| Криптография Windows | CryptoPro CSP, CAdESCOM | Bridge-каркас подготовлен |
| Локальный адаптер | C# .NET Framework 4.8 x64 | Исходный код есть, запуск требует Windows-проверки |
| Серверная БД | Microsoft SQL Server | Схема MSIGN существует |
| Внешняя интеграция | НетрИка | Есть таблицы задач, протокол требует уточнения |

## Словарь

- **CSP**: криптопровайдер, выполняющий криптографические операции.
- **CAdESCOM**: COM-интерфейс для создания и проверки CAdES-подписей.
- **CAdES-BES**: базовый формат CAdES-подписи.
- **Отсоединённая подпись**: подпись хранится отдельно от исходного файла.
- **Присоединённая подпись**: подписанные данные включены в контейнер подписи.
- **Thumbprint**: отпечаток сертификата, используемый для его однозначного выбора.
- **Bridge**: локальный процесс-посредник между Flutter и Windows COM API.

## Источники проекта

- Архив интеграционного модуля `medialog_sign_cryptopro_module.zip`.
- Перечень таблиц схемы `MSIGN` и версия SQL Server из обсуждения проектирования БД.
- Исходные Dart-файлы, предоставленные в проектных обсуждениях.
- Официальная документация CryptoPro SDK, переданная архивом. Конкретные API и требования следует сверять с версией установленного SDK.
