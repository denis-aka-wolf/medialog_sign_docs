# Сборка и запуск

## Flutter Desktop

Для Windows Desktop необходимы:
- Windows 10/11 x64.
- Flutter SDK с поддержкой Windows Desktop.
- Visual Studio 2022 с workload Desktop development with C++.
- Включённая поддержка Windows Desktop.

Проверка окружения:

```powershell
flutter doctor -v
flutter config --enable-windows-desktop
```

В корне Flutter-проекта:

```powershell
flutter pub get
flutter run -d windows
```

Если каталог `windows/` отсутствует, он генерируется командой:

```powershell
flutter create --platforms=windows .
```

Запускайте команду из каталога, где находится `pubspec.yaml`. Ошибка `Expected to find project root in current working directory` означает, что Flutter не обнаружил корень проекта в текущем каталоге.

## Release

```powershell
flutter build windows --release
```

Обычно результат находится в `build\\windows\\x64\\runner\\Release\\`. Для переноса копируйте весь каталог Release, а не только EXE.

## CryptoPro Bridge

Требования:
- Visual Studio 2022 / Build Tools с .NET desktop build tools.
- .NET Framework 4.8 Developer Pack.
- CryptoPro CSP и CAdESCOM, зарегистрированный для x64.
- Тестовый сертификат с доступным закрытым ключом.

Сборка: открыть `MedialogSign.CryptoProBridge.csproj`, конфигурация `Release | x64`.

## Путь к bridge

Dart-клиент принимает `executablePath` в конструкторе `CryptoProBridgeClient`. Путь к собранному EXE должен задаваться конфигурацией приложения. Не полагаться на относительный путь без проверки рабочего каталога.

## Проверка перед запуском

1. Проверить `flutter doctor -v`.
2. Проверить, что текущий каталог содержит `pubspec.yaml`.
3. Проверить зависимости через `flutter pub get`.
4. Убедиться, что bridge собран под x64.
5. Выполнить `status` и `list-certificates` на Windows с CryptoPro.
6. Убедиться, что приложение не пишет секреты в логи.
