## Статус документации

Документы формируются по исходным материалам, доступным на 25 ноября 2026 года: обсуждениям проекта, перечню таблиц SQL Server и архиву интеграционного модуля. Где фактическая реализация ещё не подтверждена запуском или исходным кодом, это явно отмечено как **требует проверки**.

## Принципы

1. Не выдавать проектируемое поведение за реализованное.
2. Не хранить в репозитории закрытые ключи, PIN-коды, пароли, реальные сертификаты и персональные данные.
3. Для изменений архитектуры фиксировать решение в [[docs/08-Решения-и-допущения|журнале решений]].
4. Документацию и ссылки между страницами поддерживать в формате Obsidian Markdown.
